# Portfolio Professionnel

Application web de portfolio construite en PHP/Twig avec une architecture MVC légère.

## Contenu
- Présentation de deux pôles de compétences : assistance administrative/commerciale et développement web & mobile.
- Sections : Accueil, À propos, Services, Réalisations, Compétences, Témoignages et Contact.
- Design responsive basé sur Tailwind CSS et icônes FontAwesome.
- Formulaire de contact simulé en JavaScript et téléchargement de CV.

## Lancement
1. Installer les dépendances Composer (`twig/twig`).
2. Lancer un serveur PHP : `php -S localhost:8000 -t public`.
3. Ouvrir [http://localhost:8000](http://localhost:8000).

_(Les données et images sont fictives pour la démonstration.)_
